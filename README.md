MSE: Mean Squared Error
--> Aim to minimize big errors
--> The lower is MSE, the better is the algorithm. Though, having 0 does not mean perfect, because it will often result in overfitting.

RMSE: Root Mean Squared Error
--> MSE but Rooted

MAE: Mean Absolute Error
--> Average between predicted values and true values.

R2 :
--> Maybe the best metric to compare two models
--> Go from 0 to 1: 0 = same as the average. 1 = perfect
